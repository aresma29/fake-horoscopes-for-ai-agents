# Fake Horoscopes for AI Agents

A fake horoscope written for an AI agent: this week, Venus aligns with your token budget — and a human will paste a 200-page PDF at 4:59 p.m. and call it "a quick question." Mercury offers no help.

## How it works

Run `python3 main.py` and it prints the horoscope line from `entry.txt`.
